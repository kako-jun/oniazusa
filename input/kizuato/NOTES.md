# Kizuato Reference Notes

These images are reference material for background processing only.

## Comparison rule

- Ignore foreground character stand sprites.
- Treat the rest of the image as valid reference material.
- Pay particular attention to the background treatment near the left and right edges.

## Why

The goal of `oniazusa` is background processing for visual-novel style scenes, not character rendering.
The most useful comparison areas in these references are the non-character background regions,
especially the edge-side atmosphere, tone transitions, and grid-like structure.
